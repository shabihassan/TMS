KIA Macca Motors — Cheque Writer

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in Google Chrome or Microsoft Edge.
3. Add vendors in the Vendors tab.
4. Prepare cheque details and use Preview / Print.
5. Use Print Alignment to calibrate positions.

IMPORTANT
- This is a browser-based starter application. Vendor and payment history are saved in this browser's local storage on this computer only.
- No data is uploaded to a server. Clear browser data or use another browser/profile and local records may not be available.
- The preview is a generic positioning template, NOT an exact HBL cheque layout.
- Before printing on an original cheque leaf, print test pages on plain paper and compare against a blank cheque leaf. Configure alignment carefully.
- Never upload or store cheque signatures, full account numbers, or banking credentials in this app.
- Confirm the exact HBL cheque dimensions and field positions with your bank/sample cheque before live use.
